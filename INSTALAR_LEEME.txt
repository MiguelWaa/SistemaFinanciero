SIGSF 5.6.0

1. Descomprima TODO el ZIP.
2. Instale Java 17+ y ejecute INICIAR_DEMO.bat (Windows) o sh INICIAR_DEMO.sh.
3. Abra http://localhost:8091/. Demo: admin@sigsf.com / admin123.
4. Abra DOCUMENTACION_INTEGRAL.html para pruebas, base de datos y evidencias.

Para modificar código use NetBeans y un JDK completo 17+.
Las pruebas completas necesitan Python 3.10+, Node 20+ y Chromium de Playwright.
La aplicación de demostración no necesita Node, Python ni PostgreSQL.
