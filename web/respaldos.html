Generar respaldo de la base de datos

El sistema usa pg_dump si está instalado (respaldo completo: estructura + datos). Si no lo encuentra, genera un script SQL con los datos usando JDBC. Además se hace un respaldo automático cada 24 h y se conservan los últimos 10 archivos.
Restaurar: ejecute scripts\restaurar_bd.bat archivo.sql o abra el archivo en el Query Tool de pgAdmin sobre la base SistemaFinanciero. Los respaldos jdbc contienen solo datos: ejecute antes db/schema.sql.
