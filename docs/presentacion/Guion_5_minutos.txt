de seguridad

2. Alcance y entorno de evaluación
35 segundos. El sistema separa interfaz, API Java y persistencia. La revisión se concentra en autenticación, permisos, entradas y pagos. Compilamos 216 clases y 36 archivos de prueba. Los DAO en memoria permiten repetir los ensayos sin alterar información real. La integración JDBC necesita una prueba adicional con PostgreSQL. Fuentes: src/, db/, compilación actual.

3. Plan de pruebas de seguridad
50 segundos. El plan incluye controles de acceso, entradas, deserialización y configuración. Integramos JSON estricto, rechazo de tipos de contenido y CSP para scripts externos. El fuzzing usa 20 entradas pequeñas. Los ejecutores JDBC y ZAP están implementados pero sus herramientas faltan aquí. La auditoría npm fue autorizada y encontró 21 paquetes señalados; sus correcciones siguen pendientes. Referencias: https://wstg.owasp.org/ y https://www.rfc-editor.org/info/rfc8259/ .

4. Herramientas elegidas
40 segundos. JUnit y Newman comprueban backend y API. Python coordina la ejecución y registra resultados sin confundir pendientes con aprobados. Playwright conserva el flujo de interfaz y añade una prueba de ayuda con CSP. PostgreSQL, ZAP y análisis de dependencias tienen ejecutores dentro de scripts/. Sus informes actuales reflejan los bloqueos. Enlaces en el anexo 12. npm audit terminó con hallazgos. Dependency-Check para JAR y ZAP siguen pendientes. Evidencia: evidencias/v5.6.0/sca/npm_autorizado/npm-audit.json.

5. Resultados obtenidos
55 segundos. Se mantienen 214 JUnit, 63 aserciones API y 24 comprobaciones adicionales aprobadas. La auditoría npm autorizada señaló 21 paquetes: uno crítico, trece altos y siete moderados. El criterio high no se cumple. Son dependencias de herramientas de pruebas; no se probó explotación en Java. Las correcciones están pendientes. Los 14 casos de navegador no se reejecutaron; los 13 históricos siguen como antecedente. Evidencia: evidencias/v5.6.0/sca/npm_autorizado/. Interpretación de metavulnerabilidades: https://docs.npmjs.com/cli/v11/commands/npm-audit/ .
